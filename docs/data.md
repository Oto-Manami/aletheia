# 1 つの素材（アセット）が持つ情報

アーカイブの基本の単位は**素材（アセット）**。1 枚の写真、1 本の動画、1 ページ分の誌面、保存した 1 つの Web ページなどが、それぞれ 1 つの素材になる。素材は**投稿**（一緒に出た素材のまとまり。SNS の 1 投稿、ブログの 1 記事、雑誌の 1 号など）に属する。

構造の正は `supabase/migrations/` の SQL。この一覧は、その要点を日本語でまとめたもの。

## 素材そのもの（`assets`）

| まとまり       | 項目               | キー                                     | 内容                                                                                                              |
| -------------- | ------------------ | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 何の素材か     | 種類               | `media_type`                             | `image` 画像・`video` 動画・`audio` 音声・`text` 文章・`webpage` Web ページ（1 ファイルの HTML）・`document` 文書 |
|                | 題名               | `title`                                  |                                                                                                                   |
|                | 説明               | `description`                            |                                                                                                                   |
|                | 投稿の中の順番     | `position`                               | 投稿の中で何番目か。元の並びのまま見せるために使う                                                                |
|                | 種類ごとの属性     | `attributes`                             | 誌面のページ（`page_from`・`page_to`・`page_label`）、映像の切り出し（`clip_from`・`clip_to`、秒）                |
| いつのものか   | 日付と精度         | `content_date`・`content_date_precision` | 投稿日と違うとき（撮影日など）。精度は年・月・日                                                                  |
|                | 日時               | `content_at`                             | 時刻まで分かるとき。JST                                                                                           |
| ファイルの性質 | SHA-256            | `sha256`                                 | 完全に同じファイルを見つける。同じファイルは 1 つだけ保存する                                                     |
|                | 見た目のハッシュ   | `phash`                                  | 画像・動画の似たものを見つける（転載・逆引き）                                                                    |
|                | 形式・大きさ       | `mime_type`・`byte_size`                 |                                                                                                                   |
|                | 縦横・長さ         | `width`・`height`・`duration_ms`         |                                                                                                                   |
|                | 元のファイル名     | `original_filename`                      |                                                                                                                   |
| 保存の扱い     | ファイルの保存     | `file_policy`                            | `stored` 保存している・`reference_only` 同じ内容のまとまりの代表に任せ、記録と元の URL だけを持つ                 |
|                | 同じ内容のまとまり | `content_group_id`                       | 複数の SNS への同時投稿、生配信とアーカイブ、再掲載など                                                           |
|                | 整理の状態         | `status`                                 | `organized`・`archived`                                                                                           |
| 公開区分       | 公開・非公開       | `classification`                         | `public`・`private`。既定は `private`                                                                             |

## 投稿から受け継ぐ情報（`posts`・`channels`）

素材は自分では持たず、属する投稿から読む。

| 項目           | キー                                       | 内容                                                                       |
| -------------- | ------------------------------------------ | -------------------------------------------------------------------------- |
| 情報源         | `channel_id`                               | 公式ブログ・SNS のアカウント・雑誌など。情報源ごとに有料・無料の既定を持つ |
| 投稿の ID      | `external_id`                              | 情報源の中での ID。同じ投稿は何度取り込んでも 1 つ                         |
| 題名           | `title`                                    |                                                                            |
| 投稿日時・日付 | `published_at`・`published_date`（＋精度） | JST                                                                        |
| 元の URL       | `url`                                      |                                                                            |
| 取り込んだ日時 | `captured_at`                              | ページを保存した日時                                                       |
| 有料・無料     | `availability`                             | 情報源の既定を上書きするときだけ                                           |
| 公開区分       | `classification`                           |                                                                            |

## 中身の文字（`asset_texts`）

1 つの素材に、種類の違う文字をいくつでも持てる。検索の主な対象。

| 項目       | キー                 | 内容                                                                                               |
| ---------- | -------------------- | -------------------------------------------------------------------------------------------------- |
| 種類       | `text_type`          | `body` 本文・`caption` キャプション・`ocr` 誌面の文字・`transcript` 書き起こし・`alt` 代替テキスト |
| 内容       | `content`            |                                                                                                    |
| 検索用の形 | `normalized_content` | 全角・半角などをそろえた形（自動で作る）                                                           |
| 出どころ   | `origin`             | `human` 人・`rule` 規則・`import` 移行・`ai` AI（使うのは運営者が処理ごとに決めたときだけ）        |
| 確信度     | `confidence`         | 0〜1。人が入れたものは 1                                                                           |
| 公開区分   | `classification`     |                                                                                                    |

## ファイル実体（`asset_files`）

1 つの素材が、原本と派生のファイルを持てる。データベースには置き場所だけを持ち、ファイルは Google Drive に置く。

| 項目            | キー                      | 内容                                                                                              |
| --------------- | ------------------------- | ------------------------------------------------------------------------------------------------- |
| 種類            | `variant`                 | `original` 原本・`thumbnail` サムネイル・`preview` 表示用・`transcoded` 変換したもの              |
| 保存先          | `provider`・`storage_key` | 保存先の名前と、その中での ID                                                                     |
| SHA-256・大きさ | `sha256`・`byte_size`     |                                                                                                   |
| 照合した日時    | `verified_at`             | 保存したファイルが壊れていないことを最後に確かめた日時。90 日を過ぎるとデータ品質の検査で知らせる |
| 公開区分        | `classification`          |                                                                                                   |

## 結びつき（`links`）

素材（または投稿）が、誰・何と、どんな役割で結びつくか。

| 項目     | キー                                         | 内容                                                                                                                                                |
| -------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 行き先   | `to_type`・`to_id`                           | 人物・グループ・作品など（`entity`）、出来事（`event`）、出来事の中の 1 項目（`event_item`。セットリストの 1 曲など）、語彙（`term`）               |
| 役割     | `role`                                       | `depicts` 写っている・`speaks` 話している・`appears` 出演・`author` 書いた人・`mentions` 言及・`covers` 取り上げた出来事・`part_of` 掲載・収録 など |
| 出どころ | `origin`・`confidence`・`evidence`           | 誰（人・規則）が付けたか、確信度、根拠                                                                                                              |
| 確認     | `review_state`・`reviewed_by`・`reviewed_at` | 人が確かめたか（`accepted`・`rejected`）、誰が・いつ                                                                                                |
| 公開区分 | `classification`                             |                                                                                                                                                     |

## すべての行に共通

| 項目               | キー                       | 内容                                                                                                   |
| ------------------ | -------------------------- | ------------------------------------------------------------------------------------------------------ |
| ID                 | `id`                       | UUID                                                                                                   |
| 公開区分           | `classification`           | 既定は `private`。公開サイトに出るのは `public` かつ承認済みのものだけで、有料の素材そのものは出さない |
| 作った・変えた日時 | `created_at`・`updated_at` |                                                                                                        |
| 変更履歴           | `app.history`              | 更新・削除の前の行と、変えた人を自動で残す                                                             |
